# Team Lobo — Assessoria Esportiva (Site Oficial)

Projeto desenvolvido para publicação no **GitHub Pages** (`zacode-tech.github.io/TeamLobo`).

## Estrutura de Arquivos
- `index.html` — Estrutura semântica, SEO local, Schema.org e conteúdo extraído do portal oficial e perfis do Instagram.
- `style.css` — Design system responsivo com suporte nativo a **Tema Claro** e **Tema Escuro** via variáveis CSS.
- `script.js` — Controle de tema persistente, menu mobile, links diretos para WhatsApp, contadores e animações de rolagem.
- `assets/` — Coloque aqui o arquivo `teamlobo.jpg` (logo oficial da Team Lobo) que você já possui no repositório.

## Como publicar no GitHub
1. Substitua os arquivos `index.html`, `style.css` e `script.js` na raiz do seu repositório.
2. Mantenha a pasta `assets/` com a imagem `teamlobo.jpg` (os arquivos `lobo.webp`, `homem.webp` e `mulher.webp` não são mais necessários).
3. Faça o commit e push para a branch `main`.
